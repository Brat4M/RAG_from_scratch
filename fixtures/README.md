# Test Fixtures & Sample Content

This directory houses small, human-readable, user-supplied sample documents, text passages, and test fixtures shared across learning tracks.

---

## 📋 Fixture Policy

1. **User-Supplied Content Only:**
   - Place sample PDF files, technical papers, or test markdown documents directly in this directory or clear subdirectories.
   - Do **not** generate synthetic mock datasets or commit large proprietary corpora.

2. **Size Guidelines:**
   - Keep sample files compact (under 5 MB where possible) so tests and notebooks execute with minimal latency.
   - For tiny algorithm tests, prefer deterministic inline text snippets inside the notebook itself.

3. **Format Expectations:**
   - Text files: `.txt`, `.md`
   - Document formats: `.pdf`
   - Evaluation pairs (when user-supplied): `.json`, `.csv`
